## 项目简介

MoonBPMN 计划为 MoonBit 生态实现一套可复用的 BPMN 2.0 工作流基础设施，面向流程建模工具、低代码平台、业务规则系统、CI 流程检查、教学软件和嵌入式工作流场景，提供类型化流程模型、BPMN XML 导入导出、静态语义校验、确定性 Token 执行、执行日志、快照恢复以及流程图导出能力。

项目不会将 BPMN 简化为普通有向图。实现将覆盖开始与结束事件、任务、排他网关、并行网关、顺序流和条件表达式等可执行核心语义，并对暂不支持的 BPMN 元素返回明确诊断，避免静默忽略导致流程行为失真。核心库计划兼容 MoonBit Native、Wasm、Wasm GC 与 JavaScript 后端，以便同一套流程语义同时服务于命令行工具、浏览器应用和其他 MoonBit 项目。

## 核心功能范围

- 提供类型化 BPMN 流程模型，支持 Process、Start/End Event、Task、Exclusive/Parallel Gateway 和 Sequence Flow；
- 提供命名空间感知的 BPMN 2.0 XML 导入，以及确定性的规范化 XML 导出；
- 提供稳定、可定位的诊断系统，覆盖重复 ID、悬空引用、事件约束、节点度数和不支持元素；
- 提供可达性、完成路径、循环、网关 split/join 一致性与可静态判断的死锁检查；
- 实现确定性 Token 执行语义，支持任务完成、排他分支、并行分叉与汇合；
- 提供流程变量和一个边界清晰、可测试的小型条件表达式语言；
- 提供追加式执行事件日志，以及实例快照、恢复和重放能力；
- 提供 `validate`、`normalize`、`run` 和 `replay` 命令行入口；
- 支持 JSON 诊断报告与 Mermaid/DOT 流程图导出；
- 提供 Native、Wasm、Wasm GC 和 JavaScript 多后端测试；
- 提供不少于 100 个单元、集成、畸形输入与回归测试；
- 提供 README、API 文档、可运行示例和 BPMN 兼容范围说明。

## 原创或参考说明

- 参考标准：Business Process Model and Notation（BPMN）Version 2.0.2
- 标准组织：Object Management Group（OMG）
- 标准链接：https://www.omg.org/spec/BPMN/2.0.2/
- 本项目许可证：Apache License 2.0

MoonBPMN 是原创 MoonBit 实现，不复制其他 BPMN 引擎的源代码。项目会参考 BPMN 公开规范定义数据模型、合法性约束和执行语义，并通过自行编写的测试模型验证行为。若后续引入第三方测试夹具或参考某个开源项目的具体行为，将在 `THIRD_PARTY.md` 中记录来源、版本、许可证和使用范围。

与公开可检索的相邻 MoonBit 项目相比，现有 UML/PlantUML 项目主要负责图形描述和 SVG 渲染；MoonBPMN 的核心交付是 BPMN 语义模型、静态验证和 Token 执行运行时，不以 UML 渲染为目标。

## 开发与验收计划

截至 2026 年 10 月 9 日，项目已经完成第一阶段可运行版本：领域模型、
稳定诊断码、结构与完成路径校验、类型化变量、排他分支、并行分叉与汇合、
确定性 Token 执行、有序事件日志、JSON 报告、Mermaid 导出以及端到端示例。
当前 MoonBit 源码超过 1,400 行，其中非测试源码超过 1,100 行；21 个测试会
分别在 Native、Wasm、Wasm GC 和 JavaScript 后端运行。公开仓库已经建立
连续的实质功能提交，GitHub Actions 覆盖格式、严格检查、构建、测试、接口
生成和示例运行，并主动检查 `moonc` 不低于 0.10.14。
