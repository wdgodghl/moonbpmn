## 2. 项目简介

MoonBPMN 是使用 MoonBit 原创实现的 BPMN 工作流基础库，为流程建模工具、低代码平台和业务系统提供流程模型、静态校验与确定性执行能力。项目实现事件、任务、网关、条件顺序流和 Token 流转等核心语义，并对错误模型给出可定位、可机器读取的诊断。

## 3. 项目方向与通用性

项目方向为**工作流基础设施与开发者工具**。核心库不绑定业务、界面或服务器框架，可运行于 Native、Wasm、Wasm GC 和 JavaScript 后端，被命令行工具、浏览器编辑器、后端系统及其他 MoonBit 项目复用。首版聚焦 BPMN 2.0 可执行子集。

## 4. 预期使用场景

1. **低代码平台校验**：平台提交用户绘制的流程；校验器检查重复 ID、悬空引用、不可达节点和错误网关，返回带元素 ID 和错误码的 JSON，供编辑器定位修改。
2. **业务审批执行**：订单或报销系统加载已校验模型并传入流程变量；执行器选择条件分支、处理并行汇聚，输出有序日志供业务追踪。
3. **GitHub CI 检查**：团队提交流程定义后自动执行校验、测试和 Mermaid 导出；错误模型阻止合并，成功结果用于评审和文档展示。

## 5. 拟实现的核心功能

- 类型化流程模型与图查询 API；
- 身份、引用、可达性、完成路径和网关规则校验；
- 流程变量、确定性 Token 执行、排他分支及并行汇聚；
- 有序事件日志、JSON 报告和 Mermaid/DOT 导出；
- BPMN XML 导入导出、快照恢复、事件重放、多命令 CLI、多后端测试与示例。

目前已完成可运行的第一阶段版本和 21 项测试，MoonBit 源码超过 1,400 行。

## 6. 原创、参考与许可证说明

MoonBPMN 是原创项目，不移植或复制现有 BPMN 引擎代码，因此无移植来源需要申报。项目依据 Object Management Group 的 [BPMN 2.0.2 标准](https://www.omg.org/spec/BPMN/2.0.2/)设计规则，采用 Apache-2.0 许可证；如后续引入第三方材料，将记录来源、版本、许可证和用途。
